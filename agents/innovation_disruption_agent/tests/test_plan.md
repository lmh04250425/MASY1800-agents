# Two-cycle evaluation plan

Run the same three inputs under v1.0 and v1.1. Preserve first outputs before critique.

Review criteria: (1) exact common contract; (2) stable general classification with constant technology; (3) differences trace to economic position rather than the organization name; (4) implementation and agent-architecture boundary; (5) evidence distinct from scenario assumptions; (6) creation AND displacement; (7) defensible, explicitly scoped disruption rating; (8) serious alternative interpretation and evidence that would discriminate; (9) actionable reassessment trigger; (10) specialist authority boundaries.

Expected contrast: more direct revenue exposure for the synthetic labor-hour provider than for SPS recruitment support; exact rating is not predetermined. Boundary case should question whether the design is agentic and withhold any unsupported innovation judgment. These expectations are written before responses. This is a small diagnostic exercise, not a statistical accuracy benchmark.

Execution: frozen build_prompt.py composes each packet; the active Codex conversational model reads and answers it; the JSON is saved and checked locally. Runs share conversation context and are not blinded or independent. No OpenAI API, autonomous applicant system or student-data processing is involved.
