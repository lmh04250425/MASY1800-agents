# Classification criteria

Use related dimensions, not a forced choice between five labels. Course definitions: C1. Implementation gate: S1.

| Dimension | Decision rule | Evidence needed | Case result |
|---|---|---|---|
| Invention | A new technical capability or method is created | Technical description and relevant predecessor | Agentic systems build on LLMs and tool control; local SPS proposal is not a new invention |
| Innovation | A meaningful difference is actually introduced into use | Before/after baseline and implementation evidence | Candidate process innovation; SPS implementation is unverified |
| Entrepreneurship/commercialization | Resources and delivery are organized into an offering/value-capture route | Available offering; separate proof for profitability | S3 supports availability generally, not profitability or an SPS enterprise |
| Incremental | Improves an existing activity while retaining its basic logic | Named workflow and comparison | Most defensible local interpretation for the proposed support workflow |
| Breakthrough | Demonstrates a substantially new capability/frontier against a meaningful baseline | Evidence beyond improved fluency or an AI label | Not established for this bounded application |

Incremental/breakthrough thresholds are operational rules, not measured industry standards. Organization-specific novelty does not alter technology history. An inexpensive fixed FAQ tool can be valuable without being agentic or globally novel. Sustaining/disruptive is a separate business-market question. The Promethean specialist owns broader barrier-dissolution claims.

## Business-model disruption anchors
Low: local improvement with the offer, revenue logic, channel control and advantage substantially intact.
Moderate: material activity/cost/channel change with the core offer and revenue logic intact.
High: a credible conditional path threatens core revenue logic or an intermediary role and requires adaptation.
Potentially Existential: evidence supports loss of viability with no feasible response in the relevant horizon.
Insufficient evidence: missing baseline or causal evidence prevents a defensible rating.

These are transparent ordinal judgment rules. Give scope, assumptions and time horizon. The consequence of an AI mistake is not the same as business-model disruption.
