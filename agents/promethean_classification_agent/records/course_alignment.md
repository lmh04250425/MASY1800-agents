## Student extensions to the course instrument

Each extension is labelled in the criteria file. They were added because cycle 1 showed the instrument can be misapplied to a young technology:

- the present-tense suppression test using dependence evidence only;
- the "dissolution in progress, not yet testable" result and the floor/ceiling report;
- prospective Layer 3 scores;
- the evidence admissibility table;
- counting a tier only when it is reorganizing, not merely exposed;
- the significance-weight scale;
- the incremental-counterfactual test.

The instructor's slide 20 places generative AI at "Potential Promethean ?". This package does not dispute that exemplar. It evaluates a narrower system (agentic AI) and declines to inherit the label, as Layer 1 requires.
